## Services

- `galantes_web_v4`: Next.js storefront and API routes.
- `galantes_odoo`: Odoo backend with `galantes_jewelry` addon.
- `galantes_db`: PostgreSQL.
- `galantes_nginx`: public reverse proxy inside Docker network.
- `galantes_tunnel_prod`: Cloudflare Tunnel. Must stay running during normal deploys.

## Persistent Data

- PostgreSQL database: `galantes_prod`.
- Odoo volume: `galantesjewelry_odoo-data`.
- Postgres volume: `galantesjewelry_postgres-data`.
- App runtime data: `/home/yoeli/galantesjewelry/data`.
- Product images and galleries: Odoo product image fields and `galantes.product.gallery`.

- `https://galantesjewelry.com/api/health`

## Required Secrets

Configure these in GitHub Environment `production`:

- `GCP_VM_IP`
- `GCP_SSH_PRIVATE_KEY`
- `GCP_SSH_USER` optional, defaults to `yoeli`

Production runtime secrets stay on the VM in `.env.prod` and must not be regenerated by GitHub Actions.

Configure these in GitHub Environment `staging`:

- `STAGING_SSH_HOST`
- `STAGING_SSH_USER`
- `STAGING_SSH_KEY`
- `STAGING_SSH_PORT`
- `ADMIN_PASSWORD`
- `ADMIN_SECRET_KEY`
- `POSTGRES_PASSWORD`
- `ODOO_PASSWORD`
- `ODOO_API_KEY`
- `STRIPE_SECRET_KEY_STAGING`
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY_STAGING`
- Google OAuth, Calendar, and Gmail/SMTP secrets required by staging.
- `CF_TUNNEL_TOKEN_STAGING`
